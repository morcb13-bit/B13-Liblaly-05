# Nature Knows Only Addition ― 立体から高次元へ ―

## この本について

平面のペンローズは立体の切り口で、立体は6次元の影でした。この本では、足し算だけで一段ずつ次元を上げ、52次元まで進みます。

高い次元の図形は、低い次元の図形を中に抱えた入れ子になっています。この本では、それを「次元のマトリョーシカ」と呼びます。3次元で閉じない正四面体の紐や30面体の管は、4次元の600胞体の中で閉じます。φ の入る形は4次元で終わりますが、2倍の次元の整数の格子を写すと、φ 倍の二つの殻としてまた現れます。

13次元までは、頂点と面を全部数えて確かめます。14次元から52次元までは、B13 の13の番地に整数を2つ、4つと置いて作り、作ったものを整数の行列で検算します。どの章も、走らせる前に基準を決めた検定の結果と、動く図で書いています。
